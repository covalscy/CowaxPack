# Руководство по пересчёту координат и точек вращения (calc.py)

Данное руководство объясняет логику работы скрипта [`calc.py`](../calc.py) и правила переноса моделей техники из **Blockbench** в конфигурационные JSON-файлы мода **SuperbWarfare** (в папке `data/cowaxpack/sbw/vehicles/`).

---

## 1. Разница систем координат

| Параметр | Blockbench | Minecraft / SuperbWarfare | Правило преобразования |
| :--- | :--- | :--- | :--- |
| **Единицы** | Пиксели (16 px = 1 блок) | Блоки (1 блок = 1.0) | Значения делятся на **16.0** |
| **Ось X** | Вправо (+) / Влево (-) | Влево (+) / Вправо (-) | **Инверсия знака** ($-X$) |
| **Ось Y** | Вверх (+) / Вниз (-) | Вверх (+) / Вниз (-) | Без изменения знака ($+Y$) |
| **Ось Z** | Вперед (+) / Назад (-) | Назад (+) / Вперед (-) | **Инверсия знака** ($-Z$) |

### Формула глобальной конвертации:
$$X_{\text{game}} = -\frac{X_{\text{bb}}}{16}, \quad Y_{\text{game}} = \frac{Y_{\text{bb}}}{16}, \quad Z_{\text{game}} = -\frac{Z_{\text{bb}}}{16}$$

---

## 2. Иерархия вращения и относительные координаты

Техника в SuperbWarfare имеет иерархическую структуру поворотных узлов:

```
Корпус (Body / Chassis)
 └── Башня (Turret)  [Вращается вокруг оси Y (Yaw)]
      └── Орудие / Ствол (Barrel / Gun)  [Вращается вокруг оси X (Pitch)]
           └── Точка выстрела (Muzzle / Emitter)
```

### Почему нельзя использовать абсолютные координаты везде?
1. **Башня (`turret`)** вращается относительно **корпуса**. Её пивот задаётся относительно центра модели корпуса:
   $$\text{Turret Pivot} = \text{blockbench\_to\_game}(X_{\text{turret}}, Y_{\text{turret}}, Z_{\text{turret}})$$

2. **Ствол (`barrel`)** вращается относительно **башни**. Поэтому координаты пивота ствола задаются **относительно пивота башни**:
   $$\text{Barrel Relative} = \text{relative\_position}(X_{\text{barrel\_bb}}, Y_{\text{barrel\_bb}}, Z_{\text{barrel\_bb}}, X_{\text{turret\_bb}}, Y_{\text{turret\_bb}}, Z_{\text{turret\_bb}})$$

3. **Точка дульного среза / пулемёта (`weapons`, `emitters`)**:
   - Если оружие поднимается вместе со стволом $\rightarrow$ рассчитывается относительно **пивота ствола (`barrel_pivot`)**.
   - Если оружие поворачивается только с башней $\rightarrow$ рассчитывается относительно **пивота башни (`turret_pivot`)**.

## 3. Функции в `calc.py`

### `blockbench_to_game(x, y, z)`
Переводит глобальные координаты точки/пивота из Blockbench в координаты игры.
```python
def blockbench_to_game(x, y, z):
    return -x / 16, y / 16, -z / 16
```

### `relative_position(target_x, target_y, target_z, pivot_x, pivot_y, pivot_z)`
Находит вектор смещения дочернего элемента `target` относительно родительского центра вращения `pivot`.
```python
def relative_position(target_x, target_y, target_z, pivot_x, pivot_y, pivot_z):
    rel_x = (target_x - pivot_x) / 16
    rel_y = (target_y - pivot_y) / 16
    rel_z = (target_z - pivot_z) / 16
    return -rel_x, rel_y, -rel_z
```

### `size_from_blockbench(width, height, depth)`
Конвертирует линейные габариты OBB (Oriented Bounding Box) / хитбоксов из пикселей в блоки (знаки остаются положительными).
```python
def size_from_blockbench(width, height, depth):
    return width / 16, height / 16, depth / 16
```

## 4. Пошаговый пример: Настройка пушки 2С6 Зенитки

Предположим, в Blockbench вы выставили следующие пивоты (Pivot Point):
- **Pivot башни:** `(0, 31.0107, -9.4632)`
- **Pivot блока стволов:** `(0, 48.1665, -26.1027)`
- **Точка выхода снаряда левого автомата:** `(-13.6662, 49.9302, -28.3568)`

### Шаг 1. Расчёт пивота башни:
```python
turret_game = blockbench_to_game(0, 31.0107, -9.4632)
# Результат: [0.0, 1.938169, 0.59145]
```
Вставляется в JSON техники:
```json
"turret": {
  "pivot": [0.0, 1.938169, 0.59145]
}
```

### Шаг 2. Расчёт пивота ствола относительно башни:
```python
barrel_rel = relative_position(0, 48.1665, -26.1027, 0, 31.0107, -9.4632)
# Результат: [0.0, 1.072238, 1.039969]
```
Вставляется в `barrelPivot` внутри секции башни:
```json
"barrelPivot": [0.0, 1.072238, 1.039969]
```

### Шаг 3. Расчёт дульного среза относительно ствола:
```python
muzzle_rel = relative_position(-13.6662, 49.9302, -28.3568, 0, 48.1665, -26.1027)
# Результат: [0.854138, 0.110231, 0.140881]
```
Вставляется в координаты точки спавна снаряда/эффекта выстрела.

## 5. Быстрый чеклист при добавлении новой техники

1. **Создайте модель в Blockbench** и выровняйте корпус так, чтобы земля/гусеницы были на $Y = 0$, а центр тяжести/поворота корпуса на $X = 0, Z = 0$.
2. **Задайте Pivot Points** для групп:
   - Корпус (`body`)
   - Башня (`turret`)
   - Стволы / Орудия (`barrel` / `gun`)
   - Люки, радары, вспомогательные механизмы
3. **Откройте `calc.py`**, вставьте значения пивотов и запустите скрипт.
4. **Скопируйте рассчитанные числа** в соответствующий JSON техники в `src/main/resources/data/cowaxpack/sbw/vehicles/<имя_техники>.json`.
5. **Проверьте в игре**: Башня и стволы должны вращаться ровно по осям без смещений и «отрывов» от геометрии модели.
