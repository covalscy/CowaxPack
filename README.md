# CowaxPack

CowaxPack - это мод для Minecraft, добавляющий зенитную установку "Зенитка" в игру SuperbWarfare.

## Описание

Этот мод добавляет зенитную установку, основанную на логике Terminator из VVP пакета. Зенитка предназначена для борьбы с воздушными целями и имеет следующие характеристики:

- **Здоровье**: 400 HP
- **Скорость**: 0.5 (медленная, как и положено зенитке)
- **Броня**: 8.0
- **Прочность брони**: 4.0
- **Оружие**: 
  - Основная пушка (урон: 80, взрывной урон: 40, радиус взрыва: 4)
  - Пулемет (урон: 15)

## Установка

1. Убедитесь, что у вас установлены:
   - Minecraft 1.20.1
   - Forge 47.2.0
   - SuperbWarfare
   - GeckoLib

2. Соберите проект:
   ```bash
   ./gradlew build
   ```

3. Поместите полученный .jar файл в папку mods



## Особенности

- Зенитка имеет систему перезарядки
- Поддерживает камуфляж
- Имеет реалистичную физику движения
- Интегрирована с системой урона SuperbWarfare

## Зависимости

- SuperbWarfare (обязательно)
- GeckoLib (обязательно)
- Curios (опционально)
